# sales-report-processor
This project processes supplier reports (TXT/PDF) containing invoice and delivery data, transforming unstructured data into structured insights for sales and operations.

It is designed based on real-world workflows in B2B industrial sales, where report processing is often manual and time-consuming.

- Upload TXT/PDF reports
- Parse key data (orders, clients, products, status)
- Store structured data
- Display results in a simple dashboard

🚧 MVP in development
